Found a bug, an accessibility gap, or unexpected behavior? Please report it — issues are triaged and a11y bugs are treated as high priority.

<LinkButton href="https://github.com/Kishan009/UI-Library/issues/new" variant="primary" icon="warning">Report a bug on GitHub</LinkButton>
<LinkButton href="https://github.com/Kishan009/UI-Library/discussions" variant="secondary" icon="comment">Ask a question instead</LinkButton>

## What to include

A good report gets fixed faster. Please include:

- **AxisUI version** and which package (e.g. `@axisui-ng/forms@0.0.1`).
- **Angular version** and whether the app is zoneless or Zone.js.
- **Reproduction** — a minimal StackBlitz/repo, or exact steps.
- **Expected vs. actual** behavior.
- **Environment** — browser + OS (and SSR, if relevant).
- For accessibility issues — the assistive tech / keyboard interaction involved.

## Questions vs. bugs

- **A bug** (something is broken or wrong) → [GitHub Issues](https://github.com/Kishan009/UI-Library/issues/new).
- **A question** (how do I…?) or an **idea** → [GitHub Discussions](https://github.com/Kishan009/UI-Library/discussions), or see [Support](/support/).

Security issue? Please **do not** open a public issue — see [SECURITY.md](https://github.com/Kishan009/UI-Library/blob/main/SECURITY.md).
