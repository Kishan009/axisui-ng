## Modern. Modular. Precise.

<div class="ax-pillars">
  <div class="ax-pillar ax-pillar--modern">

    <p>Signals-first (<code>input()</code> / <code>output()</code> / <code>model()</code>), standalone, OnPush, and zoneless-ready. No <code>NgModule</code>, no legacy — a native Angular library, not a React port.</p>

## Install & use

```bash
# everything, one install:
ng add @axisui-ng/angular

# or install only what you need:
npm i @axisui-ng/buttons @axisui-ng/forms
```

```ts
import { Component } from '@angular/core';
import { AxButtonComponent } from '@axisui-ng/angular';

@Component({
  selector: 'app-demo',
  imports: [AxButtonComponent],
  template: `<ax-button variant="primary">Click me</ax-button>`,
})
export class DemoComponent {}
```
